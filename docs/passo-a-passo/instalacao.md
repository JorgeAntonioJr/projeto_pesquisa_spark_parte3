# 🛠️ Guia de Instalação e Execução

Siga as etapas abaixo para configurar a execução do PySpark e das dependências no ambiente Ubuntu.

## 1. Pré-requisitos do Sistema

| Recurso | Mínimo | Recomendado |
| :--- | :--- | :--- |
| **Python** | 3.10+ | 3.12+ |
| **RAM** | 4 GB | 8 GB |

!!! warning "Atenção"
    Certifique-se de ativar o ambiente virtual antes de executar os scripts do Spark.
